# 🛡 PhishReport v1.0
Automated Phishing / Malware Analysis Report Generator built in Bash

## 🔥 Features
- SHA256, SHA1, MD5 hashing
- VirusTotal API integration (free)
- GeoIP lookup of embedded IPs
- Static string analysis
- Hybrid Analysis sandbox link
- Generates professional HTML + TXT reports

## 🛠 Requirements
sudo apt install curl jq binutils file

## ⚡ Usage
git clone https://github.com/prarthanamishra2007-prog/PhishReport.git
cd PhishReport
chmod +x phishreport.sh modules/*.sh
./phishreport.sh
